# Idlu

Gerenciador de contas para jogos idle de navegador, para Windows. Mantém cada conta conectada e isolada gastando o mínimo do PC, com o modo Eco. Não joga por você: só administra.

**Baixar:** pegue o `Idlu-Setup-<versão>.exe` do [lançamento mais recente](https://github.com/slayner/idlu-releases/releases/latest). Depois de instalado, o Idlu se atualiza sozinho.

O Windows pode avisar que o instalador não é de um editor reconhecido (ainda não é assinado): clique em "Mais informações" e "Executar assim mesmo".

Este repositório só guarda os instaladores e o `catalog.json`, a biblioteca de jogos que o Idlu baixa.
